# Який HTTP метод використовується

## Відповідь

POST

## Обґрунтування

1. Метод створює новий запис у системі. На це вказує і назва методу AddContact, і призначення в описі.
2. Дані передаються у тілі запиту у форматі JSON. GET за специфікацією HTTP не призначений для передавання тіла запиту, тому не підходить.
3. Метод не ідемпотентний. Повторний виклик з тими самими даними не має перезаписати попередній результат, він створює нову спробу створення запису. Це виключає PUT, який призначений для повної заміни ресурсу за відомим ідентифікатором.
4. PATCH застосовується для часткового оновлення вже існуючого запису за його ідентифікатором. На момент виклику методу ідентифікатора запису в системі ще немає, бо контакт тільки створюється.

## Приклад запиту

```
POST http(s)://{URL}/api/v1/contacts
Content-Type: application/json
```
