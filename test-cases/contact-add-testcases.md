# Тест-кейси: POST /api/v1/contacts

Позначки пріоритетів і правила роботи з даними описані в `docs/03-test-approach.md`.

Скорочення в постумовах: «прибрати створене» означає видалити з бази всі записи, створені або підготовлені в межах цього кейса.

---

## TC-001

Пріоритет: P1
Тип: позитивний
Назва: Створення контакту з усіма заповненими валідними полями

Передумови: у базі немає контакту з Code CT-001 і немає контакту з MobilePhone +380671110001

Тіло запиту:
```json
{
  "Code": "CT-001",
  "Name": "Test User Alpha",
  "MobilePhone": "+380671110001",
  "Email": "test.alpha@example.com",
  "BirthDate": "1990-05-14",
  "GenderCode": "0"
}
```

Очікуваний результат: запит виконано успішно, контакт створено. Усі шість переданих значень збережені у відповідні поля обʼєкта Contact згідно мапінгу. Поле Стать має значення Жіночий.

Постумови: створений контакт CT-001 видалено з бази
